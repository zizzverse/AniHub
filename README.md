# AniHub — Phase 1 Frontend

A responsive anime discovery website built with plain HTML, CSS, and vanilla JavaScript.

## Included
- Premium dark black + purple theme
- Responsive desktop and mobile layout
- Anime discovery cards with CSS-generated artwork
- Search and genre filters
- Anime details modal
- Latest episode demo list
- Banner ad and video ad placeholder areas
- No login or account requirement

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For best results, use a local static server or VS Code Live Server.

## Free hosting
You can deploy this static site using GitHub Pages or Cloudflare Pages:
1. Create a GitHub repository named `anihub`.
2. Upload all files and folders, keeping the same structure.
3. Connect the repository to Cloudflare Pages, or enable GitHub Pages.
4. Set the build command to none and the output directory to `/` (or the repository root).

## Important before public launch
- The anime entries and artwork are demo placeholders.
- Do not upload, embed, or monetize copyrighted anime unless you have distribution and advertising rights.
- Ad spaces are placeholders only. Integrate an ad provider only after approval and follow its policies.
- This frontend does not yet contain a streaming backend, real episode sources, admin panel, analytics, or ad SDK.
- Never expose private API keys in frontend JavaScript.
